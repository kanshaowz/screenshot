# 🌸 Screenshot - 网页截图工具

一个温馨友好的网页截图工具，采用粉色柔和设计风格。

## ✨ 特性

- 🎨 **自定义尺寸** - 支持自定义截图宽度和高度
- ⚡ **快速生成** - 使用现代 API 技术，快速捕获高质量截图
- 🔒 **隐私安全** - 通过 API 服务生成，无需服务器
- 🌍 **多语言支持** - 支持 5 种语言：中文、English、Español、日本語、한국어

## 🚀 使用

1. 访问网站：https://kanshaowz.github.io/screenshot
2. 输入要截图的网页 URL
3. 设置截图选项（尺寸、格式、延迟）
4. 点击"截图"按钮
5. 下载生成的截图

## 🛠️ 技术栈

- HTML5 + CSS3
- Vanilla JavaScript
- Microlink API (截图服务)
